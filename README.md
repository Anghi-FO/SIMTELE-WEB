# SIMTELE-WEB: Panel Interactivo de Prevención y Monitoreo

Aplicación web educativa desarrollada en **Programación Web I** que simula el monitoreo operacional de un sistema de transporte por cable (inspirado en Mi Teleférico).

> **Aviso:** Todos los umbrales y cálculos de esta página son simulaciones didácticas y no representan límites operativos reales.

## Módulos del sistema
1. **Detención de Emergencia:** Calcula la distancia de reacción d = (v / 3.6) \tiempo (t) y evalúa si supera el umbral didáctico de 50 m.
2. **Mantenimiento Activo:** Permite registrar, visualizar y eliminar componentes mediante un arreglo de objetos en JavaScript (`push` y `splice`).
3. **Viento y Oscilación:** Procesa 5 lecturas simuladas usando arreglos e iteraciones (`forEach`), mostrando promedio, máximo, clasificación y gráfica SVG dinámica.
4. **Monitoreo de Sensores:** Valida códigos con la expresión regular (`/^SEN-\d{3}$/`) y verifica campos vacíos o no numéricos antes de registrar.
